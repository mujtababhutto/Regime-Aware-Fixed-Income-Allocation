# Data access and provenance

The raw datasets are intentionally excluded from this repository.

The submitted analysis used monthly asset returns and macro-financial indicators assembled from sources that included Bloomberg and public economic databases such as FRED. Some source files may therefore be subject to licence, redistribution, or institutional-access restrictions.

## Files expected by the original notebook

- `Asset Data.xlsx`
- `master_indicators_dataset_monthly.csv`
- `master_indicators_dataset_processed.csv`

Authorised users should place these files in the repository root before running the original notebook. Do not commit them unless redistribution rights have been confirmed for every underlying series.

## Public-release rule

Only include data that is clearly public, redistributable, and documented with its source and retrieval date. Where redistribution is not permitted, provide a schema, source list, and preparation instructions instead of the data itself.
